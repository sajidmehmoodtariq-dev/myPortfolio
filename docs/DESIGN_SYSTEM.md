# Design system

| Token | Value | Use |
| --- | --- | --- |
| Canvas | `#0B1310` | Page ground |
| Surface | `#17211C` | Recessed panels |
| Elevated | `#202C25` | Raised planes |
| Border | `#293830` | Decorative dividers and grid |
| Accent | `#E78A55` | Spline, active markers, focus ring |
| Ink | `#F3F4EF` | Primary text |
| Muted | `#94A69B` | Supporting text and labels |

Use Geist for headlines and body copy and Geist Mono for short technical labels. Keep body copy at 16px or larger, with approximately 1.6 line height and a 65-character measure. Compose tight display headings with fluid sizing and preserve generous negative space around the assembly. Use angular edges, thin rules, and restrained surfaces. Keep screenshot colors intact. The technical grid stays low contrast and decorative. Interactive outlines need a stronger treatment than decorative borders.

Use a 76rem max-width container and fluid page gutters from 1.25rem to 3rem. Under 48rem, order copy before media in one column. Put annotations beneath the visual when leader lines would crowd the copy. At 64rem and above, use side-by-side composition where the scene benefits from it. Preserve the reading order and keep the orange path out of text contrast areas. Check text and controls at 200% zoom.

Keep the visual language close to the reference’s dark green ground, cool assembly planes, thin orange loop, and restrained annotation. Avoid repeated card grids, excessive rounding, neon decoration, glass overlays, filler copy, and decorative motion.
